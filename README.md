# Monokai Vibrant Amped

## A sweet, dark and saturated theme inspired by Monokai Vibrant

A super-clean theme with a high contrast inspired by Monokai Vibrant. I suppose another name for this would be Monokai Vibrant (High Contrast), but I think I have made enough changes to warrant it having it's own name.

* Super dark and rich editor color scheme
* Super saturated colours with high contrast for easier readability
* Uses #232323 and #1a1a1a - the indisputable best dark colours.
